# 🎤 Audio File Translator 🌍

This project is a simple **audio file translator** that can convert speech to text, translate it to a desired language, and then read the translated text aloud. It uses Python, **Speech Recognition**, **Google Translate**, and **Text-to-Speech** technologies for seamless performance.

## 🔑 Features:
- **🗣️ Speech-to-Text**: Converts speech from audio files into text.
- **🌐 Language Translation**: Translates recognized text to a target language of your choice.
- **🔊 Text-to-Speech**: Reads out the translated text in the chosen language.
- **🖱️ Drag-and-Drop**: Easily drag and drop your audio file for translation.
- **🎵 Playback**: Play and pause the audio playback of the translated text.
- **💬 Multi-language Support**: Support for various languages via Google Translate.

## 🚀 Technologies Used:
- **Speech Recognition**: Converts speech to text.
- **Google Translate API**: For translating text into different languages.
- **gTTS (Google Text-to-Speech)**: Converts translated text into speech.
- **Tkinter**: For building the graphical user interface.
- **Pygame**: For audio playback.

## 🎨 Interface:
- **📂 Drag-and-Drop** an audio file to begin.
- **🌐 Language Selection**: Enter the language code (e.g., 'fr' for French, 'de' for German).
- **🔊 Play and Pause Audio**: Playback of translated text.

## ⚙️ Usage:
1. **Drag and drop** an audio file to the window.
2. **Choose** a language for translation.
3. **Play the translated audio** or pause anytime.
4. **Enjoy** the convenience of speech-to-text translation at your fingertips!
